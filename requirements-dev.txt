# cassette-miss key as the actual CI failure), despite requirements.lock's
# sentence-transformers==2.7.0 nominally contradicting requirements.txt's >=5.7.0 floor
# (a separate, already-flagged, deliberately-parked drift -- see DEPENDENCIES.md and the
# PYSEC-2026-3716 entry). The lock is not "the wrong environment" for this purpose; it's
# demonstrably what CI already resolves to today, just made reproducible instead of
# floating. Dev-only tooling below (matplotlib, pytest, ruff, ...) stays unpinned --
# these never touch a hashed cache key.
